# 🌿 LimeTree — Curated Lifestyle Marketplace

A modern, responsive e-commerce web application uniting three distinct signature businesses under one unified shopping basket:

1. **👕 Clothing — Riyaa Trends**
   - Products: Heavyweight Organic Cotton T-shirts, French Terry Shorts, Performance Flex Track Pants
   - Size options (XS–XXL), interactive color swatches, stock availability, and quick cart addition.

2. **🕯️ Scented Candles — Glow Home**
   - Products: Hand-poured 100% natural soy & coconut botanical candles
   - Fragrance profiles (top/heart/base scent notes), burn times (50–60 hours), crackling wooden wicks, and reusable apothecary vessels.

3. **💎 Studs — Earkart**
   - Products: Certified D-color moissanite solitaires, vintage emerald-cut halos, natural freshwater baroque pearls, and geometric studs
   - 100% hypoallergenic, solid 925 sterling silver, 18K gold vermeil, and secure backing details.

---

## ✨ Features

- **Consolidated Shopping Cart**: Purchase items across Riyaa Trends, Glow Home, and Earkart in one checkout.
- **Brand Aesthetic**: Fresh lime green (`#84cc16`), crisp white, and warm light beige (`#fdfbf7`) stone tones.
- **Vector Brand Logo & Favicon**: Custom handcrafted SVG logo emblem with citrus and botanical motif.
- **Interactive Product Details Modal**: Multi-angle image gallery, size buttons, color swatches, and live specifications.
- **Slide-Out Cart Drawer**: Animated free shipping progress milestone bar, quantity increment/decrement, and live promo code validation (`LIMETREE10`).
- **Multi-Step Checkout**: Shipping address form with 1-click demo autofill, payment selection (Card, UPI/Apple Pay, Cash on Delivery), and instant order receipt generation.
- **User Authentication**: Login & registration modal with 1-click test user demo login.
- **Search & Filtering**: Real-time search with keyboard shortcut (`/`), category tabs, subcategory pills, price range slider, and multi-option sorting.
- **Fully Responsive**: Mobile drawer navigation, optimized touch interactions, and fluid layouts across mobile, tablet, and desktop.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Run

1. Clone the repository:
   ```bash
   git clone <your-github-repo-url>
   cd limetree
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
